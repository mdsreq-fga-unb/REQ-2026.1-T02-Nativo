    UC11 - Gerenciar Acervo de Áudios

    Voltar para Casos de Uso

    1. Atores

    Atores principais: Administrador, Professor, Usuário autenticado

    2. Objetivo

    Permitir que administradores e professores cadastrem, associem, desassociem e excluam arquivos de áudio do acervo, bem como permitir que usuários reproduzam os áudios associados às traduções para ouvir a pronúncia correta do idioma Munduruku.

    3. Pré-condições

    1. O ator deve estar autenticado no aplicativo.
    2. O administrador ou professor deve possuir permissão para gerenciar áudios.
    3. A tradução à qual o áudio será associado deve existir.
    4. O sistema deve possuir conexão ativa com o backend.
    5. O backend deve estar integrado ao banco de dados Firebase/Firestore e ao serviço de armazenamento de arquivos.

    4. Fluxo Principal

    FP01 - Cadastrar e Associar Áudio

    1. O administrador ou professor acessa os detalhes de uma tradução. (RF42)
    2. O sistema apresenta as informações da tradução e os áudios associados. (RF40, RF42)
    3. O ator seleciona a opção de adicionar áudio. (RF39)
    4. O sistema apresenta a interface para upload de um arquivo de áudio ou gravação utilizando o microfone do dispositivo. (RF39)
    5. O ator seleciona um arquivo ou grava um novo áudio. (RF39)
    6. O ator confirma o cadastro. (RF39)
    7. O sistema valida as informações fornecidas. (RF39)
    8. O sistema registra o áudio no acervo. (RF39)
    9. O sistema associa o áudio à tradução selecionada. (RF42)
    10. O sistema atualiza a tela exibindo o botão de reprodução do áudio. (RF40, RF42)
    11. O sistema exibe mensagem de sucesso informando que o áudio foi cadastrado e associado. (RF39, RF42)

    5. Fluxos Alternativos

    FA01 - Reproduzir Áudio

    1. O usuário acessa uma tradução que possui áudio associado. (RF40)
    2. O sistema apresenta o botão de reprodução do áudio. (RF40)
    3. O usuário seleciona a opção de reprodução. (RF40)
    4. O sistema executa o áudio na própria interface. (RF40)

    FA02 - Desassociar Áudio

    1. O administrador ou professor seleciona um áudio associado a uma tradução. (RF43)
    2. O ator seleciona a opção de desassociar. (RF43)
    3. O sistema solicita confirmação da operação. (RF43)
    4. O ator confirma a desassociação. (RF43)
    5. O sistema remove apenas o vínculo entre o áudio e a tradução. (RF43)
    6. O sistema atualiza a interface da tradução. (RF43)
    7. O sistema exibe mensagem de sucesso informando que o áudio foi desassociado. (RF43)

    FA03 - Excluir Áudio do Acervo

    1. O administrador ou professor seleciona um áudio do acervo. (RF41)
    2. O ator seleciona a opção de exclusão definitiva. (RF41)
    3. O sistema solicita confirmação da operação. (RF41)
    4. O ator confirma a exclusão. (RF41)
    5. O sistema remove o áudio do armazenamento e do banco de dados. (RF41)
    6. O sistema remove automaticamente as associações existentes. (RF41)
    7. O sistema atualiza a listagem do acervo. (RF41)
    8. O sistema exibe mensagem de sucesso informando que o áudio foi removido. (RF41)

    FA04 - Cancelar Operação

    1. Durante o cadastro ou associação de um áudio, o ator seleciona a opção de cancelar ou voltar. (RF39, RF42)
    2. O sistema descarta as alterações não salvas. (RF39, RF42)
    3. O sistema retorna para a tela anterior. (RF39, RF42)
    4. Nenhum áudio é cadastrado ou associado. (RF39, RF42)

    6. Fluxos de Exceção

    FE01 - Permissão de Microfone Negada

    1. O ator seleciona a opção de gravar um novo áudio. (RF39)
    2. O sistema solicita acesso ao microfone do dispositivo. (RF39)
    3. O sistema identifica que a permissão foi negada. (RF39)
    4. O sistema bloqueia a gravação. (RF39)
    5. O sistema orienta o ator a habilitar a permissão nas configurações do dispositivo. (RF39)

    FE02 - Formato de Áudio Não Suportado

    1. O ator seleciona um arquivo incompatível. (RF39)
    2. O sistema identifica que o formato não é suportado. (RF39)
    3. O sistema rejeita o arquivo. (RF39)
    4. O sistema informa os formatos aceitos pelo sistema. (RF39)

    FE03 - Tradução Indisponível

    1. O ator tenta associar ou visualizar um áudio vinculado a uma tradução. (RF40, RF42, RF43)
    2. O sistema verifica a existência da tradução. (RF40, RF42, RF43)
    3. O sistema identifica que a tradução foi removida ou encontra-se indisponível. (RF40, RF42, RF43)
    4. O sistema impede a operação. (RF40, RF42, RF43)

    FE04 - Usuário Sem Permissão

    1. Um usuário sem perfil de administrador ou professor tenta gerenciar áudios. (RF39, RF41, RF42, RF43)
    2. O sistema identifica a ausência das permissões necessárias. (RF39, RF41, RF42, RF43)
    3. O sistema bloqueia o acesso às funcionalidades administrativas. (RF39, RF41, RF42, RF43)
    4. O sistema informa que o acesso é restrito. (RF39, RF41, RF42, RF43)

    FE05 - Falha de Conectividade

    1. O ator tenta executar uma operação envolvendo áudios sem conexão com o backend. (RF39, RF40, RF41, RF42, RF43)
    2. O sistema não consegue concluir a operação. (RF39, RF40, RF41, RF42, RF43)
    3. O sistema exibe mensagem de falha de conexão. (RF39, RF40, RF41, RF42, RF43)
    4. O sistema orienta o ator a tentar novamente quando a conexão for restabelecida. (RF39, RF40, RF41, RF42, RF43)

    FE06 - Erro Interno no Armazenamento

    1. O ator confirma uma operação válida envolvendo áudios. (RF39, RF40, RF41, RF42, RF43)
    2. O sistema tenta armazenar, remover ou recuperar o áudio. (RF39, RF40, RF41, RF42, RF43)
    3. O serviço de armazenamento retorna erro ou indisponibilidade. (RF39, RF40, RF41, RF42, RF43)
    4. O sistema cancela a operação. (RF39, RF40, RF41, RF42, RF43)
    5. O sistema exibe mensagem de erro interno. (RF39, RF40, RF41, RF42, RF43)
