# 9 · DoR e DoD

Esta seção apresenta os critérios usados para preparar e encerrar itens de trabalho no backlog. A Definition of Ready (DoR) mostra quando uma demanda está madura para entrar em desenvolvimento, enquanto a Definition of Done (DoD) define o que precisa estar concluído para que a entrega seja considerada finalizada.

<div class="section-cards">
  <a class="section-card" href="dor/">
    <h3>9.1 Definition of Ready (DoR)</h3>
    <p>Conjunto de condições mínimas para que um item esteja pronto para ser planejado e desenvolvido com clareza e previsibilidade.</p>
  </a>
  <a class="section-card" href="dod/">
    <h3>9.2 Definition of Done (DoD)</h3>
    <p>Critérios que comprovam a finalização do item, incluindo implementação, revisão, testes, documentação e validação da entrega.</p>
  </a>
