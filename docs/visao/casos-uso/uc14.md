# UC14 - Candidatar-se a Professor

[Voltar para Itens de Trabalho](../backlog.md#101-casos-de-uso)

## 1. Atores

**Atores principais:** Usuário autenticado

## 2. Objetivo

Permitir que um usuário autenticado solicite a obtenção do perfil de professor para atuar na plataforma, enviando uma solicitação que será analisada pelos administradores.

## 3. Pré-condições

1. O ator deve estar autenticado no aplicativo.
2. O ator deve possuir uma conta de usuário ativa.
3. O ator não pode possuir perfil de professor.
4. O ator não pode possuir uma solicitação de professor com status Pendente.
5. O sistema deve possuir conexão ativa com o backend.
6. O backend deve estar integrado ao banco de dados Firebase/Firestore.

## 4. Fluxo Principal

**FP01 - Solicitar Perfil de Professor**

1. O usuário autenticado acessa a tela de configurações do perfil. ([RF25](#uc14-rf25))
2. O sistema identifica o perfil do ator autenticado. ([RF25](#uc14-rf25))
3. O sistema verifica que o ator ainda não possui perfil de professor. ([RF25](#uc14-rf25))
4. O sistema apresenta a opção "Solicitar Perfil de Professor". ([RF25](#uc14-rf25))
5. O ator seleciona a opção de solicitação. ([RF25](#uc14-rf25))
6. O sistema apresenta o formulário de candidatura. ([RF25](#uc14-rf25))
7. O ator informa os dados solicitados, incluindo justificativa e, opcionalmente, documentos comprobatórios. ([RF25](#uc14-rf25))
8. O ator confirma o envio da solicitação. ([RF25](#uc14-rf25))
9. O sistema valida os dados obrigatórios informados. ([RF25](#uc14-rf25))
10. O sistema registra a solicitação no banco de dados com status Pendente. ([RF25](#uc14-rf25))
11. O sistema notifica os administradores sobre a nova solicitação. ([RF25](#uc14-rf25))
12. O sistema exibe mensagem informando que a solicitação foi enviada com sucesso e aguarda análise. ([RF25](#uc14-rf25))

## 5. Fluxos Alternativos

**FA01 - Cancelar Solicitação**

1. Durante o preenchimento do formulário, o ator seleciona a opção Cancelar. ([RF25](#uc14-rf25))
2. O sistema descarta os dados informados que ainda não foram enviados. ([RF25](#uc14-rf25))
3. O sistema retorna o ator para a tela de configurações do perfil. ([RF25](#uc14-rf25))

## 6. Fluxos de Exceção

**FE01 - Solicitação Já Pendente**

1. O ator confirma o envio da solicitação. ([RF25](#uc14-rf25))
2. O sistema verifica que já existe uma solicitação com status Pendente para o ator. ([RF25](#uc14-rf25))
3. O sistema impede o registro de uma nova solicitação. ([RF25](#uc14-rf25))
4. O sistema informa que a solicitação já está em análise. ([RF25](#uc14-rf25))

**FE02 - Campos Obrigatórios Não Preenchidos**

1. O ator tenta enviar a solicitação com campos obrigatórios ausentes ou inválidos. ([RF25](#uc14-rf25))
2. O sistema identifica as inconsistências. ([RF25](#uc14-rf25))
3. O sistema impede o envio da solicitação. ([RF25](#uc14-rf25))
4. O sistema destaca os campos inválidos. ([RF25](#uc14-rf25))
5. O sistema orienta o ator a corrigir as informações antes de realizar um novo envio. ([RF25](#uc14-rf25))

Campos obrigatórios mínimos:

- justificativa da solicitação.

**FE03 - Erro no Registro da Solicitação**

1. O ator confirma uma solicitação válida. ([RF25](#uc14-rf25))
2. O sistema tenta registrar a solicitação no banco de dados. ([RF25](#uc14-rf25))
3. O banco de dados retorna erro ou indisponibilidade. ([RF25](#uc14-rf25))
4. O sistema cancela a operação. ([RF25](#uc14-rf25))
5. O sistema informa que não foi possível concluir a solicitação e orienta o ator a tentar novamente mais tarde. ([RF25](#uc14-rf25))

**FE04 - Usuário Já Possui Perfil de Professor**

1. O ator acessa a tela de configurações do perfil. ([RF25](#uc14-rf25))
2. O sistema identifica que o ator já possui perfil de professor. ([RF25](#uc14-rf25))
3. O sistema não exibe a opção "Solicitar Perfil de Professor". ([RF25](#uc14-rf25))

**FE05 - Falha de Conectividade**

1. O ator tenta enviar a solicitação sem conexão com o backend. ([RF25](#uc14-rf25))
2. O sistema não consegue concluir a operação. ([RF25](#uc14-rf25))
3. O sistema informa a falha de conexão. ([RF25](#uc14-rf25))
4. O sistema orienta o ator a tentar novamente quando a conexão for restabelecida. ([RF25](#uc14-rf25))
