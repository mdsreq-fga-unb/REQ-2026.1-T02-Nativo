    UC08 - Gerenciar Moderação de Conteúdo

    Voltar para Casos de Uso

    1. Atores

    Atores principais: Usuário autenticado, Administrador

    2. Objetivo

    Permitir que usuários denunciem conteúdos que violem as diretrizes da comunidade e que administradores analisem e atualizem o status das denúncias.

    3. Pré-condições

    1. O ator deve estar autenticado no aplicativo.
    2. O conteúdo denunciado deve existir na plataforma.
    3. O sistema deve possuir conexão ativa com o backend.
    4. O backend deve estar integrado ao banco de dados Firebase/Firestore.

    4. Fluxo Principal

    FP01 - Criar Denúncia

    1. O usuário visualiza um conteúdo da comunidade. (RF27)
    2. O usuário seleciona a opção "Denunciar". (RF27)
    3. O sistema apresenta o formulário de denúncia. (RF27)
    4. O usuário seleciona o motivo da denúncia e, opcionalmente, informa uma descrição. (RF27)
    5. O usuário confirma o envio da denúncia. (RF27)
    6. O sistema valida as informações fornecidas. (RF27)
    7. O sistema registra a denúncia com status "Aberta", vinculando-a ao conteúdo denunciado e ao usuário responsável pela denúncia. (RF27)
    8. O sistema exibe mensagem de sucesso informando que a denúncia foi registrada. (RF27)

    5. Fluxos Alternativos

    FA01 - Listar Denúncias

    1. O administrador acessa a página de Moderação. (RF29)
    2. O sistema busca as denúncias pendentes. (RF29)
    3. O sistema apresenta a lista de denúncias ordenadas cronologicamente ou por prioridade. (RF29)
    4. O administrador seleciona uma denúncia para visualizar seus detalhes. (RF29)

    FA02 - Atualizar Status da Denúncia

    1. O administrador acessa uma denúncia existente. (RF28)
    2. O administrador analisa o conteúdo denunciado. (RF28)
    3. O administrador seleciona o novo status da denúncia. (RF28)
    4. O administrador confirma a atualização. (RF28)
    5. O sistema registra o novo status da denúncia. (RF28)
    6. O sistema remove a denúncia da fila de pendências, quando aplicável. (RF28)
    7. O sistema exibe mensagem de sucesso informando que a denúncia foi atualizada. (RF28)

    FA03 - Cancelar Denúncia

    1. Durante o preenchimento da denúncia, o usuário seleciona a opção de cancelar ou voltar. (RF27)
    2. O sistema descarta as informações preenchidas. (RF27)
    3. O sistema retorna para a tela anterior. (RF27)
    4. Nenhuma denúncia é registrada. (RF27)

    6. Fluxos de Exceção

    FE01 - Conteúdo Indisponível

    1. O usuário confirma o envio da denúncia. (RF27)
    2. O sistema verifica a existência do conteúdo denunciado. (RF27)
    3. O sistema identifica que o conteúdo foi removido ou tornou-se indisponível. (RF27)
    4. O sistema interrompe o registro da denúncia. (RF27)
    5. O sistema informa que o conteúdo não está mais disponível. (RF27)

    FE02 - Motivo da Denúncia Não Informado

    1. O usuário tenta enviar a denúncia sem selecionar um motivo. (RF27)
    2. O sistema identifica a ausência da informação obrigatória. (RF27)
    3. O sistema impede o envio da denúncia. (RF27)
    4. O sistema destaca o campo obrigatório. (RF27)

    FE03 - Denúncia Indisponível para Atualização

    1. O administrador tenta atualizar uma denúncia inexistente ou já removida. (RF28)
    2. O sistema verifica a disponibilidade da denúncia. (RF28)
    3. O sistema identifica que a denúncia não está mais disponível. (RF28)
    4. O sistema impede a atualização. (RF28)
    5. O sistema atualiza a lista de denúncias. (RF29)

    FE04 - Usuário Sem Permissão

    1. Um usuário sem permissões administrativas tenta acessar a área de moderação. (RF28, RF29)
    2. O sistema identifica a ausência de permissões necessárias. (RF28, RF29)
    3. O sistema bloqueia o acesso à funcionalidade. (RF28, RF29)
    4. O sistema informa que o acesso é restrito a administradores. (RF28, RF29)

    FE05 - Falha de Conectividade

    1. O ator tenta criar ou gerenciar denúncias sem conexão com o backend. (RF27, RF28, RF29)
    2. O sistema não consegue concluir a operação. (RF27, RF28, RF29)
    3. O sistema exibe mensagem de falha de conexão. (RF27, RF28, RF29)
    4. O sistema orienta o ator a tentar novamente quando a conexão for restabelecida. (RF27, RF28, RF29)

    FE06 - Erro Interno no Banco de Dados

    1. O ator confirma uma operação válida envolvendo denúncias. (RF27, RF28, RF29)
    2. O sistema tenta registrar, atualizar ou consultar dados no Firestore. (RF27, RF28, RF29)
    3. O banco de dados retorna erro ou indisponibilidade. (RF27, RF28, RF29)
    4. O sistema cancela a operação. (RF27, RF28, RF29)
    5. O sistema exibe mensagem de erro interno. (RF27, RF28, RF29)

    7. Regras de Negócio

    • RN15 - Categoria obrigatória e controle de status da denúncia
    • RN16 - Cancelamento da denúncia quando o conteúdo alvo é excluído

    8. Requisitos Relacionados

    RF Relação com a UC
    RF27 - Criar denúncia Permite que usuários denunciem conteúdos que violem as diretrizes da comunidade.
    RF28 - Atualizar status de denúncia Permite que administradores alterem o status das denúncias durante o processo de moderação.
    RF29 - Listar denúncias Permite que administradores visualizem as denúncias registradas na plataforma.
