# 9 · DoR e DoD

Esta seção define os critérios operacionais que usamos para gerir o backlog e garantir a entrega de valor: a Definition of Ready (DoR) especifica o que é necessário para que um item esteja pronto para ser planejado; a Definition of Done (DoD) estabelece os requisitos objetivos que comprovam que um item foi efetivamente concluído e aceito.

<div class="section-cards">
  <a class="section-card" href="dor/">
    <h3>9.1 Definition of Ready (DoR)</h3>
    <p>Critérios mínimos que um item de backlog deve satisfazer antes de ser considerado pronto para entrar em uma sprint: descrição clara, critérios de aceitação, estimativa, dependências identificadas e dados/ambiente necessários.</p>
  </a>
  <a class="section-card" href="dod/">
    <h3>9.2 Definition of Done (DoD)</h3>
    <p>Conjunto de condições que comprovam a conclusão de um item: código implementado e revisado, testes unitários e de integração executados, documentação atualizada, deploy em ambiente de integração e aceite pelo Product Owner.</p>
  </a>
</div>
