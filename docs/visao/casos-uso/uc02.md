# UC02 - Responder Atividades Educacionais

[Voltar para Casos de Uso](../backlog.md#9-casos-de-uso)

## 1. Atores

**Atores principais:** Usuário comum

## 2. Objetivo

Permitir que usuários comuns visualizem atividades educacionais disponíveis, respondam atividades publicadas e visualizem o resultado obtido após a submissão das respostas.

## 3. Pré-condições

1. O usuário deve estar autenticado no aplicativo.
2. O usuário deve possuir perfil autorizado a acessar a área de atividades educacionais.
3. O sistema deve possuir atividades educacionais previamente cadastradas.
4. As atividades disponíveis para resolução devem estar liberadas.
5. Cada atividade disponível deve possuir pelo menos uma questão válida.
6. O aplicativo deve possuir conexão com o backend para carregar atividades e submeter respostas.
7. O backend deve estar integrado ao banco de dados Firebase/Firestore.

## 4. Fluxo Principal

**FP01 - Responder Atividade Educacional**

1. O usuário acessa a seção de atividades educacionais disponíveis. ([RF50](#uc02-rf50))
2. O sistema valida se o usuário está autenticado. ([RF50](#uc02-rf50))
3. O sistema consulta as atividades educacionais disponíveis para resolução. ([RF50](#uc02-rf50))
4. O sistema exibe a lista de atividades disponíveis para o usuário. ([RF50](#uc02-rf50))
5. O usuário seleciona uma atividade disponível para resolução. ([RF03](#uc02-rf03))
6. O sistema carrega os dados da atividade selecionada. ([RF03](#uc02-rf03))
7. O sistema exibe o título da atividade, o enunciado das questões e as alternativas disponíveis. ([RF03](#uc02-rf03))
8. O usuário seleciona as respostas das questões apresentadas. ([RF03](#uc02-rf03))
9. O usuário finaliza a resolução da atividade. ([RF03](#uc02-rf03))
10. O usuário submete suas respostas. ([RF03](#uc02-rf03))
11. O sistema valida se as questões obrigatórias foram respondidas. ([RF03](#uc02-rf03))
12. O sistema envia as respostas submetidas ao backend. ([RF03](#uc02-rf03))
13. O backend processa as respostas enviadas. ([RF04](#uc02-rf04))
14. O backend compara as respostas do usuário com as alternativas corretas cadastradas. ([RF04](#uc02-rf04))
15. O backend calcula a pontuação obtida pelo usuário. ([RF04](#uc02-rf04))
16. O backend registra o resultado da atividade no banco de dados. ([RF04](#uc02-rf04))
17. O sistema exibe o resultado da atividade para o usuário. ([RF04](#uc02-rf04))
18. O usuário visualiza a correção e a pontuação obtida. ([RF04](#uc02-rf04))

## 5. Fluxos Alternativos

**FA01 - Listar Atividades Educacionais Disponíveis**

1. O usuário acessa a seção de atividades educacionais. ([RF50](#uc02-rf50))
2. O sistema consulta as atividades disponíveis para resolução. ([RF50](#uc02-rf50))
3. O sistema exibe a lista de atividades disponíveis. ([RF50](#uc02-rf50))
4. O usuário visualiza as atividades disponíveis para resolução. ([RF50](#uc02-rf50))

**FA02 - Visualizar Resultado de Atividade Já Respondida**

1. O usuário acessa a lista de atividades educacionais. ([RF50](#uc02-rf50))
2. O sistema identifica que uma atividade já possui resultado registrado para o usuário. ([RF04](#uc02-rf04))
3. O usuário seleciona a atividade já respondida. ([RF04](#uc02-rf04))
4. O sistema carrega o resultado registrado da atividade. ([RF04](#uc02-rf04))
5. O sistema exibe a correção e a pontuação obtida. ([RF04](#uc02-rf04))
6. O usuário visualiza o resultado da atividade. ([RF04](#uc02-rf04))

**FA03 - Voltar para a Lista de Atividades**

1. Durante a resolução ou após visualizar o resultado, o usuário aciona a opção de voltar. ([RF50](#uc02-rf50), [RF03](#uc02-rf03), [RF04](#uc02-rf04))
2. O sistema retorna o usuário para a lista de atividades educacionais. ([RF50](#uc02-rf50))
3. O sistema atualiza a lista de atividades disponíveis. ([RF50](#uc02-rf50))
4. O usuário visualiza novamente a lista de atividades. ([RF50](#uc02-rf50))

**FA04 - Tentar Atividade Novamente Após Erro**

1. Após visualizar o resultado da atividade, o sistema identifica que o usuário errou uma ou mais questões. ([RF04](#uc02-rf04))
2. O sistema exibe a opção de tentar a atividade novamente. ([RF03](#uc02-rf03), [RF04](#uc02-rf04))
3. O usuário aciona a opção de tentar novamente. ([RF03](#uc02-rf03))
4. O sistema carrega novamente a atividade em modo de resolução. ([RF03](#uc02-rf03))
5. O usuário responde novamente às questões da atividade. ([RF03](#uc02-rf03))
6. O usuário submete as novas respostas. ([RF03](#uc02-rf03))
7. O sistema processa a nova submissão. ([RF04](#uc02-rf04))
8. O sistema exibe o novo resultado da atividade. ([RF04](#uc02-rf04))

**FA05 - Visualizar Resultado com Todas as Questões Corretas**

1. Após a submissão da atividade, o sistema identifica que o usuário acertou todas as questões. ([RF04](#uc02-rf04))
2. O sistema calcula a pontuação máxima da atividade. ([RF04](#uc02-rf04))
3. O sistema registra o resultado da atividade. ([RF04](#uc02-rf04))
4. O sistema exibe o resultado final ao usuário. ([RF04](#uc02-rf04))
5. O sistema exibe a opção de tentar novamente. ([RF04](#uc02-rf04))

## 6. Fluxos de Exceção

**FE01 - Falha de Conectividade**

1. O usuário tenta listar atividades, carregar uma atividade, submeter respostas ou visualizar resultado sem conexão com o backend. ([RF50](#uc02-rf50), [RF03](#uc02-rf03), [RF04](#uc02-rf04))
2. O sistema não consegue concluir a operação. ([RF50](#uc02-rf50), [RF03](#uc02-rf03), [RF04](#uc02-rf04))
3. O sistema exibe mensagem de falha de conexão. ([RF50](#uc02-rf50), [RF03](#uc02-rf03), [RF04](#uc02-rf04))
4. O sistema orienta o usuário a tentar novamente quando a conexão for restabelecida. ([RF50](#uc02-rf50), [RF03](#uc02-rf03), [RF04](#uc02-rf04))

**FE02 - Atividade Indisponível ou Inválida por Estado Desatualizado**

1. O usuário visualiza uma atividade na lista antes da atualização completa do estado no banco ou na interface. ([RF50](#uc02-rf50))
2. O usuário tenta acessar a atividade para resolução. ([RF03](#uc02-rf03))
3. O sistema revalida a disponibilidade e a validade da atividade no backend. ([RF03](#uc02-rf03))
4. O sistema identifica que a atividade foi removida, desativada, tornou-se indisponível ou não possui mais questões válidas. ([RF50](#uc02-rf50), [RF03](#uc02-rf03))
5. O sistema impede a resolução da atividade. ([RF03](#uc02-rf03))
6. O sistema atualiza a lista de atividades disponíveis. ([RF50](#uc02-rf50))
7. O sistema informa que a atividade não está mais disponível para resolução. ([RF50](#uc02-rf50), [RF03](#uc02-rf03))

**FE03 - Submissão Incompleta**

1. O usuário tenta submeter a atividade sem responder todas as questões obrigatórias. ([RF03](#uc02-rf03))
2. O sistema identifica que há questões sem resposta. ([RF03](#uc02-rf03))
3. O sistema impede a submissão da atividade. ([RF03](#uc02-rf03))
4. O sistema informa que todas as questões obrigatórias devem ser respondidas. ([RF03](#uc02-rf03))
5. O usuário permanece na tela de resolução para completar as respostas. ([RF03](#uc02-rf03))

**FE04 - Erro Interno no Processamento**

1. O usuário submete respostas válidas. ([RF03](#uc02-rf03))
2. O backend tenta processar as respostas e registrar o resultado. ([RF04](#uc02-rf04))
3. Ocorre erro interno no processamento ou no banco de dados. ([RF04](#uc02-rf04))
4. O sistema não registra a atividade como concluída. ([RF04](#uc02-rf04))
5. O sistema exibe mensagem de erro. ([RF04](#uc02-rf04))
6. O sistema orienta o usuário a tentar novamente. ([RF03](#uc02-rf03), [RF04](#uc02-rf04))
