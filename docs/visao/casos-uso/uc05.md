# UC05 - Gerenciar Eventos

[Voltar para Casos de Uso](../backlog.md#9-casos-de-uso)

## 1. Atores

**Atores principais:** Usuário autenticado, Moderador

## 2. Objetivo

Permitir que usuários autenticados criem, visualizem, editem, excluam e compartilhem eventos da comunidade.

## 3. Pré-condições

1. O ator deve estar autenticado no aplicativo.
2. O ator deve possuir uma conta ativa.
3. O ator deve acessar a página de Eventos.
4. O sistema deve possuir conexão ativa com o backend.
5. O backend deve estar integrado ao banco de dados Firebase/Firestore.

## 4. Fluxo Principal

**FP01 - Criar Evento**

1. O usuário acessa a página de Eventos. ([RF15](#uc05-rf15))
2. O sistema identifica o usuário autenticado. ([RF15](#uc05-rf15))
3. O sistema apresenta a agenda de eventos e a opção de criar um novo evento. ([RF17](#uc05-rf17))
4. O usuário seleciona a opção de criar evento. ([RF15](#uc05-rf15))
5. O sistema apresenta o formulário de criação de evento. ([RF15](#uc05-rf15))
6. O usuário informa o título, data, horário, local, descrição e demais informações do evento. ([RF15](#uc05-rf15))
7. O usuário confirma a criação do evento. ([RF15](#uc05-rf15))
8. O sistema valida os dados obrigatórios. ([RF15](#uc05-rf15))
9. O sistema registra o evento no banco de dados e o vincula ao usuário criador. ([RF15](#uc05-rf15))
10. O sistema atualiza a agenda de eventos. ([RF15](#uc05-rf15), [RF17](#uc05-rf17))
11. O sistema exibe mensagem de sucesso informando que o evento foi criado. ([RF15](#uc05-rf15))

## 5. Fluxos Alternativos

**FA01 - Visualizar Eventos**

1. O usuário acessa a página de Eventos. ([RF17](#uc05-rf17))
2. O sistema busca os eventos cadastrados. ([RF17](#uc05-rf17))
3. O sistema exibe os eventos ordenados por data de realização. ([RF17](#uc05-rf17))
4. O usuário visualiza os eventos disponíveis. ([RF17](#uc05-rf17))

**FA02 - Editar Evento**

1. O criador acessa um evento de sua autoria. ([RF16](#uc05-rf16))
2. O usuário seleciona a opção de edição. ([RF16](#uc05-rf16))
3. O sistema carrega os dados atuais do evento. ([RF16](#uc05-rf16))
4. O usuário altera as informações desejadas. ([RF16](#uc05-rf16))
5. O usuário confirma a edição. ([RF16](#uc05-rf16))
6. O sistema valida os dados alterados. ([RF16](#uc05-rf16))
7. O sistema atualiza o evento no banco de dados. ([RF16](#uc05-rf16))
8. O sistema exibe mensagem de sucesso informando que o evento foi atualizado. ([RF16](#uc05-rf16))

**FA03 - Excluir Evento**

1. O criador do evento ou um moderador acessa um evento existente. ([RF18](#uc05-rf18))
2. O ator seleciona a opção de exclusão. ([RF18](#uc05-rf18))
3. O sistema solicita confirmação da exclusão. ([RF18](#uc05-rf18))
4. O ator confirma a exclusão. ([RF18](#uc05-rf18))
5. O sistema remove o evento da agenda da comunidade. ([RF18](#uc05-rf18))
6. O sistema atualiza a lista de eventos. ([RF18](#uc05-rf18), [RF17](#uc05-rf17))
7. O sistema exibe mensagem de sucesso informando que o evento foi excluído. ([RF18](#uc05-rf18))

**FA04 - Compartilhar Evento**

1. O usuário acessa um evento disponível. ([RF19](#uc05-rf19))
2. O usuário seleciona a opção de compartilhamento. ([RF19](#uc05-rf19))
3. O sistema apresenta as opções de compartilhamento disponíveis. ([RF19](#uc05-rf19))
4. O usuário seleciona o destino do compartilhamento. ([RF19](#uc05-rf19))
5. O sistema gera o link do evento e conclui o compartilhamento. ([RF19](#uc05-rf19))

**FA05 - Cancelar Criação ou Edição**

1. Durante a criação ou edição do evento, o ator aciona a opção de cancelar ou voltar. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
2. O sistema descarta as alterações não salvas. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
3. O sistema retorna para a tela anterior. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
4. Nenhum dado é registrado ou alterado no banco de dados. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))

## 6. Fluxos de Exceção

**FE01 - Interface Indisponível para Usuário Não Autenticado**

1. O usuário tenta acessar a página de Eventos sem estar autenticado. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
2. O sistema identifica que não existe uma sessão válida. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
3. O sistema impede o acesso às funcionalidades de eventos. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
4. O sistema redireciona o usuário para a tela de login. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))

**FE02 - Campos Obrigatórios Ausentes**

1. O usuário tenta criar ou editar um evento sem preencher os campos obrigatórios. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
2. O sistema identifica a ausência dos dados obrigatórios. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
3. O sistema impede o salvamento do evento. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
4. O sistema destaca os campos inválidos. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
5. O sistema orienta o usuário a preencher as informações necessárias. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))

Campos obrigatórios mínimos:

- título;
- data;
- horário;
- local.

**FE03 - Data do Evento Inválida**

1. O usuário informa uma data ou horário no passado durante a criação ou edição do evento. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
2. O sistema identifica a inconsistência. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
3. O sistema impede o salvamento do evento. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))
4. O sistema informa que o evento deve ocorrer em uma data futura. ([RF15](#uc05-rf15), [RF16](#uc05-rf16))

**FE04 - Evento Indisponível por Estado Desatualizado**

1. O usuário tenta editar, excluir ou compartilhar um evento. ([RF16](#uc05-rf16), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
2. O sistema revalida a disponibilidade do evento no backend. ([RF16](#uc05-rf16), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
3. O sistema identifica que o evento foi removido ou tornou-se indisponível. ([RF16](#uc05-rf16), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
4. O sistema impede a operação solicitada. ([RF16](#uc05-rf16), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
5. O sistema atualiza a agenda de eventos. ([RF17](#uc05-rf17))
6. O sistema informa que o evento não está mais disponível. ([RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))

**FE05 - Falha de Conectividade**

1. O usuário tenta criar, visualizar, editar, excluir ou compartilhar um evento sem conexão com o backend. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
2. O sistema não consegue concluir a operação. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
3. O sistema exibe mensagem de falha de conexão. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
4. O sistema orienta o usuário a tentar novamente quando a conexão for restabelecida. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))

**FE06 - Erro Interno no Banco de Dados**

1. O usuário confirma uma operação válida envolvendo um evento. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
2. O sistema tenta registrar, atualizar, excluir ou consultar dados no Firestore. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
3. O banco de dados retorna erro ou indisponibilidade. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
4. O sistema cancela a operação. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
5. O sistema exibe mensagem de erro interno. ([RF15](#uc05-rf15), [RF16](#uc05-rf16), [RF17](#uc05-rf17), [RF18](#uc05-rf18), [RF19](#uc05-rf19))
