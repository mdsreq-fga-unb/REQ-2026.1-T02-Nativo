# UC10 - Gerenciar Acervo de Vídeos

[Voltar para Itens de Trabalho](../backlog.md#101-casos-de-uso)

## 1. Atores

**Atores principais:** Administrador, Professor, Usuário autenticado

## 2. Objetivo

Permitir que administradores e professores cadastrem, associem, desassociem e excluam vídeos do acervo, bem como permitir que usuários reproduzam vídeos associados às traduções.

## 3. Pré-condições

1. O ator deve estar autenticado no aplicativo.
2. O administrador ou professor deve possuir permissão para gerenciar vídeos.
3. A tradução à qual o vídeo será associado deve existir.
4. O sistema deve possuir conexão ativa com o backend.
5. O backend deve estar integrado ao banco de dados Firebase/Firestore e ao serviço de armazenamento de arquivos.

## 4. Fluxo Principal

**FP01 - Cadastrar e Associar Vídeo**

1. O administrador ou professor acessa os detalhes de uma tradução. ([RF37](#uc10-rf37))
2. O sistema apresenta as informações da tradução e os vídeos associados. ([RF35](#uc10-rf35), [RF37](#uc10-rf37))
3. O ator seleciona a opção de adicionar vídeo. ([RF34](#uc10-rf34))
4. O sistema apresenta a interface para upload ou inserção do link do vídeo. ([RF34](#uc10-rf34))
5. O ator seleciona o arquivo ou informa o link do vídeo. ([RF34](#uc10-rf34))
6. O ator confirma o cadastro. ([RF34](#uc10-rf34))
7. O sistema valida as informações fornecidas. ([RF34](#uc10-rf34))
8. O sistema registra o vídeo no acervo. ([RF34](#uc10-rf34))
9. O sistema associa o vídeo à tradução selecionada. ([RF37](#uc10-rf37))
10. O sistema atualiza a tela exibindo o vídeo associado. ([RF35](#uc10-rf35), [RF37](#uc10-rf37))
11. O sistema exibe mensagem de sucesso informando que o vídeo foi cadastrado e associado. ([RF34](#uc10-rf34), [RF37](#uc10-rf37))

## 5. Fluxos Alternativos

**FA01 - Reproduzir Vídeo**

1. O usuário acessa uma tradução que possui vídeo associado. ([RF35](#uc10-rf35))
2. O sistema apresenta o player de vídeo. ([RF35](#uc10-rf35))
3. O usuário seleciona a opção de reprodução. ([RF35](#uc10-rf35))
4. O sistema reproduz o vídeo na própria interface. ([RF35](#uc10-rf35))

**FA02 - Desassociar Vídeo**

1. O administrador ou professor seleciona um vídeo associado a uma tradução. ([RF38](#uc10-rf38))
2. O ator seleciona a opção de desassociar. ([RF38](#uc10-rf38))
3. O sistema solicita confirmação da operação. ([RF38](#uc10-rf38))
4. O ator confirma a desassociação. ([RF38](#uc10-rf38))
5. O sistema remove apenas o vínculo entre o vídeo e a tradução. ([RF38](#uc10-rf38))
6. O sistema atualiza a interface da tradução. ([RF38](#uc10-rf38))
7. O sistema exibe mensagem de sucesso informando que o vídeo foi desassociado. ([RF38](#uc10-rf38))

**FA03 - Excluir Vídeo do Acervo**

1. O administrador ou professor seleciona um vídeo do acervo. ([RF36](#uc10-rf36))
2. O ator seleciona a opção de exclusão definitiva. ([RF36](#uc10-rf36))
3. O sistema solicita confirmação da operação. ([RF36](#uc10-rf36))
4. O ator confirma a exclusão. ([RF36](#uc10-rf36))
5. O sistema remove o vídeo do armazenamento e do banco de dados. ([RF36](#uc10-rf36))
6. O sistema remove automaticamente as associações existentes. ([RF36](#uc10-rf36))
7. O sistema atualiza a listagem do acervo. ([RF36](#uc10-rf36))
8. O sistema exibe mensagem de sucesso informando que o vídeo foi removido. ([RF36](#uc10-rf36))

**FA04 - Cancelar Operação**

1. Durante o cadastro ou associação de um vídeo, o ator seleciona a opção de cancelar ou voltar. ([RF34](#uc10-rf34), [RF37](#uc10-rf37))
2. O sistema descarta as alterações não salvas. ([RF34](#uc10-rf34), [RF37](#uc10-rf37))
3. O sistema retorna para a tela anterior. ([RF34](#uc10-rf34), [RF37](#uc10-rf37))
4. Nenhum vídeo é cadastrado ou associado. ([RF34](#uc10-rf34), [RF37](#uc10-rf37))

## 6. Fluxos de Exceção

**FE01 - Arquivo Acima do Limite Permitido**

1. O ator seleciona um arquivo de vídeo para upload. ([RF34](#uc10-rf34))
2. O sistema verifica o tamanho do arquivo. ([RF34](#uc10-rf34))
3. O sistema identifica que o arquivo ultrapassa o limite permitido. ([RF34](#uc10-rf34))
4. O sistema interrompe o upload. ([RF34](#uc10-rf34))
5. O sistema informa o limite máximo permitido. ([RF34](#uc10-rf34))

**FE02 - Formato de Vídeo Não Suportado**

1. O ator seleciona um arquivo incompatível. ([RF34](#uc10-rf34))
2. O sistema identifica que o formato não é suportado. ([RF34](#uc10-rf34))
3. O sistema rejeita o arquivo. ([RF34](#uc10-rf34))
4. O sistema informa os formatos aceitos pelo sistema. ([RF34](#uc10-rf34))

**FE03 - Tradução Indisponível**

1. O ator tenta associar ou visualizar um vídeo vinculado a uma tradução. ([RF35](#uc10-rf35), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
2. O sistema verifica a existência da tradução. ([RF35](#uc10-rf35), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
3. O sistema identifica que a tradução foi removida ou encontra-se indisponível. ([RF35](#uc10-rf35), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
4. O sistema impede a operação. ([RF35](#uc10-rf35), [RF37](#uc10-rf37), [RF38](#uc10-rf38))

**FE04 - Usuário Sem Permissão**

1. Um usuário sem perfil de administrador ou professor tenta gerenciar vídeos. ([RF34](#uc10-rf34), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
2. O sistema identifica a ausência das permissões necessárias. ([RF34](#uc10-rf34), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
3. O sistema bloqueia o acesso às funcionalidades administrativas. ([RF34](#uc10-rf34), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
4. O sistema informa que o acesso é restrito. ([RF34](#uc10-rf34), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))

**FE05 - Falha de Conectividade**

1. O ator tenta executar uma operação envolvendo vídeos sem conexão com o backend. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
2. O sistema não consegue concluir a operação. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
3. O sistema exibe mensagem de falha de conexão. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
4. O sistema orienta o ator a tentar novamente quando a conexão for restabelecida. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))

**FE06 - Erro Interno no Armazenamento**

1. O ator confirma uma operação válida envolvendo vídeos. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
2. O sistema tenta armazenar, remover ou recuperar o vídeo. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
3. O serviço de armazenamento retorna erro ou indisponibilidade. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
4. O sistema cancela a operação. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
5. O sistema exibe mensagem de erro interno. ([RF34](#uc10-rf34), [RF35](#uc10-rf35), [RF36](#uc10-rf36), [RF37](#uc10-rf37), [RF38](#uc10-rf38))
