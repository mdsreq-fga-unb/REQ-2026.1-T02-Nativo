# UC01 - Gerenciar Atividades Educacionais

[Voltar para Casos de Uso](../backlog.md#9-casos-de-uso)

## 1. Atores

**Atores principais:** Professor, Administrador, Moderador

## 2. Objetivo

Permitir que professores criem atividades educacionais e que professores, administradores e moderadores visualizem, editem e excluam atividades educacionais em suas respectivas páginas no aplicativo.

## 3. Pré-condições

1. O ator deve estar autenticado no aplicativo.
2. Para criar atividades, o ator deve possuir perfil de professor.
3. Para listar atividades, o ator deve possuir perfil de professor, administrador ou moderador.
4. Para editar ou excluir atividades, o ator deve possuir perfil de professor, administrador ou moderador.
5. O ator deve acessar a página de atividades correspondente ao seu perfil.
6. O sistema deve possuir conexão ativa com o backend.
7. O backend deve estar integrado ao banco de dados Firebase/Firestore.

## 4. Fluxo Principal

**FP01 - Criar Atividade Educacional**

1. O professor acessa a seção de criação de atividade educacional. ([RF01](#uc01-rf01))
2. O sistema identifica o perfil do ator autenticado. ([RF01](#uc01-rf01))
3. O sistema valida se o ator possui perfil de professor. ([RF01](#uc01-rf01))
4. O sistema apresenta o formulário de criação de atividade educacional. ([RF01](#uc01-rf01))
5. O professor informa o título da atividade. ([RF01](#uc01-rf01))
6. O professor informa, opcionalmente, a descrição da atividade. ([RF01](#uc01-rf01))
7. O professor adiciona uma ou mais questões à atividade. ([RF01](#uc01-rf01))
8. Para cada questão, o professor informa o enunciado, as alternativas disponíveis e a alternativa correta. ([RF01](#uc01-rf01))
9. O professor confirma a criação da atividade. ([RF01](#uc01-rf01))
10. O sistema valida os dados obrigatórios da atividade. ([RF01](#uc01-rf01))
11. O sistema registra a atividade no banco de dados. ([RF01](#uc01-rf01))
12. O sistema disponibiliza a atividade criada para acesso conforme as permissões dos perfis autorizados. ([RF01](#uc01-rf01), [RF02](#uc01-rf02))
13. O sistema exibe mensagem de sucesso informando que a atividade foi criada. ([RF01](#uc01-rf01))

## 5. Fluxos Alternativos

**FA01 - Listar Atividades Educacionais**

1. O professor, administrador ou moderador acessa sua página de atividades educacionais. ([RF02](#uc01-rf02))
2. O sistema identifica o perfil do ator autenticado. ([RF02](#uc01-rf02))
3. O sistema busca as atividades educacionais disponíveis para o perfil do ator. ([RF02](#uc01-rf02))
4. O sistema exibe a lista de atividades educacionais na página correspondente ao perfil do ator. ([RF02](#uc01-rf02))
5. O ator visualiza as atividades cadastradas. ([RF02](#uc01-rf02))

**FA02 - Editar Atividade Educacional**

1. O professor, administrador ou moderador acessa a lista de atividades cadastradas em sua respectiva página. ([RF02](#uc01-rf02), [RF05](#uc01-rf05))
2. O ator seleciona uma atividade existente. ([RF05](#uc01-rf05))
3. O sistema carrega os dados atuais da atividade. ([RF05](#uc01-rf05))
4. O ator altera um ou mais campos da atividade, como título, descrição, questões, alternativas ou alternativa correta. ([RF05](#uc01-rf05))
5. O ator confirma a edição da atividade. ([RF05](#uc01-rf05))
6. O sistema valida os dados alterados. ([RF05](#uc01-rf05))
7. O sistema atualiza o registro da atividade no banco de dados. ([RF05](#uc01-rf05))
8. O sistema exibe mensagem de sucesso informando que a atividade foi atualizada. ([RF05](#uc01-rf05))

**FA03 - Excluir Atividade Educacional**

1. O professor, administrador ou moderador acessa a lista de atividades cadastradas em sua respectiva página. ([RF02](#uc01-rf02), [RF06](#uc01-rf06))
2. O ator seleciona uma atividade existente. ([RF06](#uc01-rf06))
3. O ator aciona a opção de exclusão. ([RF06](#uc01-rf06))
4. O sistema solicita confirmação da exclusão. ([RF06](#uc01-rf06))
5. O ator confirma a exclusão. ([RF06](#uc01-rf06))
6. O sistema remove a atividade do banco de dados ou altera seu status para indisponível. ([RF06](#uc01-rf06))
7. O sistema exibe mensagem de sucesso informando que a atividade foi excluída. ([RF06](#uc01-rf06))

**FA04 - Cancelar Criação ou Edição**

1. Durante a criação ou edição da atividade, o ator aciona a opção de cancelar ou voltar. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
2. O sistema descarta alterações não salvas. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
3. O sistema retorna o ator para a tela anterior. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
4. Nenhum dado é registrado ou alterado no banco de dados. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))

## 6. Fluxos de Exceção

**FE01 - Interface Indisponível para o Perfil do Ator**

1. O professor, administrador ou moderador acessa o aplicativo autenticado. ([RF01](#uc01-rf01), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
2. O sistema identifica o perfil do ator autenticado. ([RF01](#uc01-rf01), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
3. O sistema exibe apenas as interfaces e ações permitidas para aquele perfil. ([RF01](#uc01-rf01), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
4. Caso o perfil do ator não possua permissão para determinada ação, a opção correspondente não é exibida na interface. ([RF01](#uc01-rf01), [RF05](#uc01-rf05), [RF06](#uc01-rf06))

**FE02 - Dados Obrigatórios Ausentes**

1. O professor tenta criar uma atividade ou o professor, administrador ou moderador tenta editar uma atividade sem preencher campos obrigatórios. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
2. O sistema identifica a ausência de dados obrigatórios. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
3. O sistema impede o salvamento da atividade. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
4. O sistema destaca os campos inválidos. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
5. O sistema orienta o ator a preencher as informações necessárias. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))

Campos obrigatórios mínimos:

- título;
- pelo menos uma questão;
- enunciado da questão;
- pelo menos duas alternativas;
- uma alternativa correta válida.

**FE03 - Alternativa Correta Inválida**

1. O ator informa uma alternativa correta inexistente ou incompatível com a lista de alternativas durante a criação ou edição da atividade. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
2. O sistema identifica a inconsistência. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
3. O sistema impede o salvamento da atividade. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))
4. O sistema exibe mensagem informando que a alternativa correta deve corresponder a uma das alternativas cadastradas. ([RF01](#uc01-rf01), [RF05](#uc01-rf05))

**FE04 - Atividade Indisponível por Estado Desatualizado**

1. O professor, administrador ou moderador visualiza uma atividade na lista antes da atualização completa do estado no banco ou na interface. ([RF02](#uc01-rf02))
2. O ator tenta acessar a atividade para edição ou exclusão. ([RF05](#uc01-rf05), [RF06](#uc01-rf06))
3. O sistema revalida a disponibilidade da atividade no backend antes de permitir a operação. ([RF05](#uc01-rf05), [RF06](#uc01-rf06))
4. O sistema identifica que a atividade foi removida, desativada ou tornou-se indisponível. ([RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
5. O sistema impede a edição ou exclusão da atividade. ([RF05](#uc01-rf05), [RF06](#uc01-rf06))
6. O sistema atualiza a lista de atividades disponíveis. ([RF02](#uc01-rf02))
7. O sistema informa que a atividade não está mais disponível para a operação solicitada. ([RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))

**FE05 - Falha de Conectividade**

1. O ator tenta criar, listar, editar ou excluir uma atividade sem conexão com o backend. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
2. O sistema não consegue concluir a operação. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
3. O sistema exibe mensagem de falha de conexão. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
4. O sistema orienta o ator a tentar novamente quando a conexão for restabelecida. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))

**FE06 - Erro Interno no Banco de Dados**

1. O ator confirma uma operação válida envolvendo uma atividade educacional. ([RF01](#uc01-rf01), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
2. O sistema tenta registrar, atualizar, excluir ou consultar dados no Firestore. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
3. O banco de dados retorna erro ou indisponibilidade. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
4. O sistema cancela a operação. ([RF01](#uc01-rf01), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
5. O sistema exibe mensagem de erro interno. ([RF01](#uc01-rf01), [RF02](#uc01-rf02), [RF05](#uc01-rf05), [RF06](#uc01-rf06))
