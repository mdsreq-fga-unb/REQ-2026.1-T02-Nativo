    UC04 - Gerenciar Feed Social

    Voltar para Itens de Trabalho

    1. Atores

    Atores principais: Usuário autenticado

    2. Objetivo

    Permitir que usuários autenticados visualizem o feed da comunidade, criem publicações, editem ou excluam suas próprias publicações e interajam com publicações de outros usuários.

    3. Pré-condições

    1. O ator deve estar autenticado no aplicativo.
    2. O ator deve possuir uma conta ativa.
    3. O ator deve acessar a página do Feed Social.
    4. O sistema deve possuir conexão ativa com o backend.
    5. O backend deve estar integrado ao banco de dados Firebase/Firestore.

    4. Fluxo Principal

    FP01 - Criar Publicação

    1. O usuário acessa a página do Feed Social. (RF10)
    2. O sistema identifica o usuário autenticado. (RF10)
    3. O sistema apresenta a lista de publicações disponíveis e a opção de criar uma nova publicação. (RF12)
    4. O usuário seleciona a opção de criar publicação. (RF10)
    5. O sistema apresenta o formulário de criação da publicação. (RF10)
    6. O usuário informa o conteúdo da publicação e, opcionalmente, anexa uma mídia. (RF10)
    7. O usuário confirma a publicação. (RF10)
    8. O sistema valida os dados informados. (RF10)
    9. O sistema registra a publicação no banco de dados e a vincula ao usuário. (RF10)
    10. O sistema atualiza o Feed Social exibindo a nova publicação. (RF10, RF12)
    11. O sistema exibe mensagem de sucesso informando que a publicação foi criada. (RF10)

    5. Fluxos Alternativos

    FA01 - Visualizar Feed Social

    1. O usuário acessa a página do Feed Social. (RF12)
    2. O sistema identifica o usuário autenticado. (RF12)
    3. O sistema busca as publicações disponíveis. (RF12)
    4. O sistema exibe as publicações ordenadas da mais recente para a mais antiga. (RF12)
    5. O usuário visualiza as publicações disponíveis. (RF12)

    FA02 - Interagir com Publicação

    1. O usuário acessa o Feed Social. (RF14)
    2. O usuário seleciona uma publicação. (RF14)
    3. O usuário realiza uma interação, como curtir ou comentar. (RF14)
    4. O sistema registra a interação. (RF14)
    5. O sistema atualiza a publicação com a nova interação. (RF14)

    FA03 - Editar Publicação

    1. O usuário acessa uma publicação de sua autoria. (RF11)
    2. O usuário seleciona a opção de edição. (RF11)
    3. O sistema carrega o conteúdo atual da publicação. (RF11)
    4. O usuário altera o conteúdo da publicação. (RF11)
    5. O usuário confirma a edição. (RF11)
    6. O sistema valida os dados alterados. (RF11)
    7. O sistema atualiza a publicação no banco de dados. (RF11)
    8. O sistema exibe mensagem de sucesso informando que a publicação foi atualizada. (RF11)

    FA04 - Excluir Publicação

    1. O usuário acessa uma publicação de sua autoria. (RF13)
    2. O usuário seleciona a opção de exclusão. (RF13)
    3. O sistema solicita confirmação da exclusão. (RF13)
    4. O usuário confirma a exclusão. (RF13)
    5. O sistema remove a publicação do banco de dados. (RF13)
    6. O sistema atualiza o Feed Social. (RF13, RF12)
    7. O sistema exibe mensagem de sucesso informando que a publicação foi excluída. (RF13)

    FA05 - Cancelar Criação ou Edição

    1. Durante a criação ou edição da publicação, o usuário aciona a opção de cancelar ou voltar. (RF10, RF11)
    2. O sistema descarta as alterações não salvas. (RF10, RF11)
    3. O sistema retorna à tela anterior. (RF10, RF11)
    4. Nenhum dado é registrado ou alterado no banco de dados. (RF10, RF11)

    6. Fluxos de Exceção

    FE01 - Interface Indisponível para Usuário Não Autenticado

    1. O usuário tenta acessar o Feed Social sem estar autenticado. (RF10, RF11, RF12, RF13, RF14)
    2. O sistema identifica que não existe uma sessão válida. (RF10, RF11, RF12, RF13, RF14)
    3. O sistema impede o acesso às funcionalidades do Feed Social. (RF10, RF11, RF12, RF13, RF14)
    4. O sistema redireciona o usuário para a tela de login. (RF10, RF11, RF12, RF13, RF14)

    FE02 - Conteúdo Obrigatório Ausente

    1. O usuário tenta criar ou editar uma publicação sem informar texto ou anexar mídia. (RF10, RF11)
    2. O sistema identifica que a publicação não possui conteúdo. (RF10, RF11)
    3. O sistema impede o envio da publicação. (RF10, RF11)
    4. O sistema informa que a publicação deve conter texto ou mídia. (RF10, RF11)

    FE03 - Mídia Inválida

    1. O usuário anexa uma mídia acima do limite permitido ou em formato não suportado. (RF10, RF11)
    2. O sistema identifica a inconsistência. (RF10, RF11)
    3. O sistema rejeita o arquivo anexado. (RF10, RF11)
    4. O sistema informa o limite ou formato permitido. (RF10, RF11)

    FE04 - Publicação Indisponível por Estado Desatualizado

    1. O usuário tenta editar, excluir ou interagir com uma publicação. (RF11, RF13, RF14)
    2. O sistema revalida a disponibilidade da publicação no backend. (RF11, RF13, RF14)
    3. O sistema identifica que a publicação foi removida ou tornou-se indisponível. (RF11, RF13, RF14)
    4. O sistema impede a operação. (RF11, RF13, RF14)
    5. O sistema atualiza o Feed Social. (RF12)
    6. O sistema informa que a publicação não está mais disponível. (RF11, RF12, RF13, RF14)

    FE05 - Falha de Conectividade

    1. O usuário tenta criar, visualizar, editar, excluir ou interagir com uma publicação sem conexão com o backend. (RF10, RF11, RF12, RF13, RF14)
    2. O sistema não consegue concluir a operação. (RF10, RF11, RF12, RF13, RF14)
    3. O sistema exibe mensagem de falha de conexão. (RF10, RF11, RF12, RF13, RF14)
    4. O sistema orienta o usuário a tentar novamente quando a conexão for restabelecida. (RF10, RF11, RF12, RF13, RF14)

    FE06 - Erro Interno no Banco de Dados

    1. O usuário confirma uma operação válida envolvendo uma publicação. (RF10, RF11, RF12, RF13, RF14)
    2. O sistema tenta registrar, atualizar, excluir, consultar ou interagir com dados no Firestore. (RF10, RF11, RF12, RF13, RF14)
    3. O banco de dados retorna erro ou indisponibilidade. (RF10, RF11, RF12, RF13, RF14)
    4. O sistema cancela a operação. (RF10, RF11, RF12, RF13, RF14)
    5. O sistema exibe mensagem de erro interno. (RF10, RF11, RF12, RF13, RF14)
